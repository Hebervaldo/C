# Controle GPIO para Raspberry Pi

Projeto desenvolvido para controle de portas GPIO em dispositivos Raspberry Pi, permitindo automação de hardware, acionamento de dispositivos eletrônicos e integração entre software e componentes físicos.

A aplicação foi criada para possibilitar gerenciamento de sinais digitais, leitura e escrita em portas GPIO, automação embarcada e experimentação com dispositivos eletrônicos conectados ao Raspberry Pi.

A solução possui arquitetura voltada para automação, controle embarcado e integração entre hardware e software, permitindo expansão para sensores, relés, LEDs, motores e outros dispositivos eletrônicos.
