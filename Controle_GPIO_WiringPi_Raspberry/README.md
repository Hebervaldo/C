# Controle GPIO com WiringPi para Raspberry Pi

Projeto desenvolvido em C utilizando biblioteca WiringPi para controle de portas GPIO em dispositivos Raspberry Pi, permitindo automação embarcada, integração com hardware eletrônico e manipulação programática de sinais digitais.

A aplicação foi criada para possibilitar leitura e escrita em portas GPIO, acionamento de dispositivos eletrônicos e desenvolvimento de soluções embarcadas utilizando Raspberry Pi sob ambiente Linux.

A solução possui arquitetura voltada para automação de hardware, sistemas embarcados, IoT e integração entre software e componentes físicos através da biblioteca WiringPi.
