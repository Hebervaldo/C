# Rede Neural 1.0

Projeto desenvolvido em linguagem C para implementação experimental de redes neurais artificiais, utilizando algoritmos próprios voltados para estudo, treinamento, processamento matemático e simulação computacional de aprendizado de máquina.

A solução foi criada com foco em desenvolvimento independente de inteligência artificial, permitindo construção manual de estruturas neurais, manipulação matemática, testes experimentais e simulação de modelos neurais sem utilização de frameworks externos de machine learning.

O projeto possui arquitetura voltada para processamento numérico, manipulação de estruturas neurais e experimentação algorítmica utilizando linguagem C de baixo nível.
