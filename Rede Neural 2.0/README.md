# Rede Neural 2.0

Projeto desenvolvido em linguagem C para implementação experimental de redes neurais artificiais, utilizando algoritmos próprios voltados para treinamento, processamento matemático e simulação computacional de aprendizado de máquina.

A versão 2.0 representa evolução da arquitetura neural anteriormente desenvolvida, com foco em melhorias estruturais, experimentação algorítmica e refinamento do processamento matemático das redes neurais implementadas.

O sistema foi desenvolvido sem utilização de frameworks externos de machine learning, permitindo controle total das estruturas neurais, processamento numérico e gerenciamento manual de memória utilizando linguagem C.
